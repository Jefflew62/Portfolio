📦 Measuring Warehouse Utilization

Capstone project for the Robotics Systems Engineering programme at SIT, built in collaboration with CEVA Logistics. The system uses overhead cameras and computer vision to provide continuous, automated monitoring of warehouse staging zone floor space — replacing manual audits with real-time data.

Images will be added soon.

The Problem

Warehouse staging areas lack automated visibility into floor space utilization. Manual audits are infrequent, labour-intensive, and produce stale data — preventing managers from optimizing pallet placement or identifying congestion before it happens.

The Solution

A stationary overhead camera system using YOLOv8 object detection and ArUco marker-based zone calibration. The team pivoted from the original AMR-based brief to a fixed camera approach — delivering continuous monitoring at a fraction of the cost, with no navigation complexity and no safety risk to floor workers.

Key Technical Details

  • Custom YOLOv8 model trained on 1,121 images across 6 classes (EU/US pallets, empty/loaded, human, forklift) — mAP50 of 0.989
  • ArUco marker-based zone boundaries with bird's-eye perspective warp correcting for 20° camera tilt
  • Three-layer utilization pipeline: raw pixel occupancy → EMA smoothing → metric-area conversion
  • ROS2 DDS two-laptop architecture: edge node for inference, server node for Flask dashboard
  • Dashboard with utilization gauges, trend charts, pallet breakdowns, and CSV export on 30-second snapshot cycles
  • 1:16 scale prototype built and validated against 25 test cases

My Role

Contributed as one of four team members (Team 10) across the full development lifecycle — from requirements analysis and CEVA Logistics site visits through hardware fabrication, software development, testing, and final demonstration.

Technologies Used

YOLOv8 ROS2 Python OpenCV Flask ArUco Markers Homography Orbbec Dabai

Outcome

Delivered a fully functional prototype at SGD $158 — approximately 87% below the initial estimate. The system achieved detection accuracy of mAP50 = 0.989 and met all project objectives for accuracy, update frequency, and deployability.
